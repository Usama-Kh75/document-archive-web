# أرشيف — نسخة المتصفح 1.2.4

نسخة مستقلة تعمل على GitHub Pages ويمكن تثبيتها كتطبيق PWA من المتصفح.
بعد الزيارة الأولى وتحميل التطبيق بنجاح، أغلقه وافتحه مرة أخرى لاستخدامه دون اتصال.
التحديثات تُحمّل عند الاتصال. تُحدّث الصفحة تلقائيًا عند وصول نسخة جديدة، وتنتظر إن كانت نافذة مفتوحة أو عملية جارية حتى تنتهي.

من الإصدار 1.2.3 أصبح معرّف التثبيت مستقلًا عن تطبيقات GitHub الأخرى.
إذا كان زر الفتح يعرض تطبيق العقود، حدّث صفحة الأرشيف ثم ثبّت «أرشيف» كتطبيق مستقل.
لا تمسح بيانات الموقع؛ تبقى المستندات في المتصفح والمسار نفسيهما.

الملفات تبقى في IndexedDB على جهازك ومتصفحك. نشر الرابط لا ينقل الأرشيف أو يزامنه.
كل جهاز يبدأ بأرشيف فارغ. التحديثات لا تحذف قاعدة البيانات؛ لا تغيّر اسمها عند تحديث الواجهة.
التخزين وذاكرة التطبيق المؤقتة منفصلان حسب مسار الموقع. تطبيقات github.io لنفس المستخدم
تشترك في الأصل الأمني وحصة التخزين؛ لذلك لا تنشر تطبيقات غير موثوقة على الأصل نفسه.

المتاح: رفع PDF وOffice والصور والمخططات، تصنيفات متفرعة، بحث في البيانات والنص اليدوي،
منع التكرار بالبصمة، تعديل البيانات، معاينة PDF وPNG وJPEG، تنزيل الأصل، سلة واستعادة،
وتصدير/استيراد .archive مع التحقق من البصمات والدمج دون حذف البيانات الموجودة.
حد الملف 100 MiB، والدفعة 20 ملفًا/100 MiB، والنسخة الاحتياطية 512 MiB، والأرشيف 10000 مستند و2000 تصنيف.
لا يوجد تسجيل دخول أو تشفير داخل التطبيق. مسح بيانات المتصفح يحذف الأرشيف؛ احتفظ بنسخة خارجية.

المسح المباشر وOCR التلقائي والصلاحيات والنسخ المجدول تتطلب نسخة Windows.
لا تنقل نسخة Windows أو بياناتها تلقائيًا؛ نسخ Windows ZIP ليست بصيغة .archive.
يمكن إضافة الملفات الأصلية يدويًا أو استعادة نسخة من نسخة المتصفح.

للبناء من المشروع المحلي: `python scripts/build_web.py` بعد تثبيت Pillow.
الناتج في `dist/web` قائمة صريحة لملفات واجهة التطبيق فقط، دون قواعد بيانات أو مستندات.
المستودع العام يستقبل ملفات الناتج وREADME فقط على فرع main، وGitHub Pages ينشر من جذر الفرع.
